# Seiko QAW109G rebuild guide

An interactive 3D model and step-by-step reassembly guide for the Seiko QAW109G pyramid skeleton clock, reconstructed from photos.

Open `index.html`, or view the live page through GitHub Pages.

- Drag to rotate, scroll or pinch to zoom, tap a part to name it.
- "Pull apart" separates the layers. The step list walks through reassembly in order.
- Parts drawn in blue are hidden in every reference photo, so their shape and position are guesses. Tooth counts are estimates.

This is an unofficial reconstruction and is not affiliated with Seiko.
